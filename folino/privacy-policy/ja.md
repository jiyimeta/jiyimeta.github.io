# folino プライバシーポリシー

最終更新日: 2026年9月27日

本プライバシーポリシーは、Harmolo（以下「当方」）が提供する楽譜アプリ folino が、iPhone・iPad・Mac・Android で情報をどのように扱うかを説明するものです。Harmolo のその他のアプリには [Harmolo プライバシーポリシー](/privacy-policy/ja/) が適用されます。

folino はアカウントなしで利用できます。楽譜の閲覧・再生・編集・書き込みにサインインは不要で、サインインしない限り楽譜は端末の外に出ません。下記「アカウント・同期・共有グループ」に記載した内容は、ユーザーがサインインを選んだ場合にのみ行われます。

## 収集する情報と利用目的

1. **クラッシュ・診断情報**
   folino は、クラッシュ発生時の診断情報（クラッシュのスタックトレース、不具合が起きるまでの操作の簡単な記録、および端末モデル・OS バージョン・アプリバージョンなどの標準的な端末情報）を、クラッシュレポートサービス（Firebase Crashlytics）を通じて収集し、安定性の向上や不具合の修正に利用します。サービスのソフトウェアが、自身の動作に関する技術的な診断情報を送信することもあります。設定 → プライバシーからクラッシュレポートをオフにできます。これらの情報はユーザーの身元とは紐付けていません。

2. **利用状況データ**
   folino は、画面の表示、使用した機能、項目の件数などの利用状況を、解析サービス（Google Analytics for Firebase）を通じて収集し、機能改善に利用します。解析サービスは、アプリと OS のバージョン、端末モデル、言語、セッションの開始と長さといった標準的な情報を、アプリのインストールごとの識別子とあわせて記録し、通信元のネットワークアドレスからおおよその位置（市区町村程度）を推定します。氏名、メールアドレス、アカウントの識別子、コンテンツ（タイトルやファイルなど）を解析サービスに送ることはなく、これらのデータはユーザーの身元とは紐付けていません。設定 → プライバシーから利用状況の送信をオフにできます。

3. **マイクの使用**（Mac）
   Mac では、音程バーが声や楽器の音の高さをリアルタイムに表示するためにマイクを使用します。取得した音声は端末上でのみ処理され、録音・保存されることはなく、当方や第三者に送信されることもありません。

4. **アカウント・同期・共有グループ**（サインインした場合に限ります）
   サインインは任意で、端末間でのライブラリの同期と、グループでの共有を利用するためのものです。サインインした場合、次の情報を収集し、アカウントと紐付けて扱います。

   - **アカウント情報**: Apple でサインイン、Google でサインイン、またはメールアドレスに届くサインイン用リンクのいずれかでサインインできます。当方はアカウントの識別子、メールアドレス（Apple でサインインの「メールを非公開」を使った場合は中継用のアドレス）、およびサインインサービスが提供した場合やユーザーが入力した場合は名前を受け取ります。サインイン用リンクを依頼すると、メールアドレスが当方のサーバーに送られ、サーバーがリンクを作成してメール配信事業者を通じて送信します。同じアドレスへの送信を繰り返し過ぎないよう制限するためだけに、アドレスを一方向に変換した値（ハッシュ）と最後に依頼された時刻を保持します。
   - **プロフィール**: ユーザーが設定した表示名と、追加した場合はプロフィール写真。写真はアップロード前に縮小され、撮影場所やカメラの情報（メタデータ）は取り除かれます。プロフィールは参加しているグループのメンバーに表示されるほか、アカウントの識別子を知っているサインイン済みの他の folino ユーザーが参照できます。
   - **楽譜と書き込み**: 同期がオンのとき（設定からいつでもオフにできます）、ライブラリの楽譜ファイル、その情報（タイトル、作曲者、ファイルサイズ、お気に入りかどうかなど）、書き込み、および音符の編集履歴（どの端末で編集したかを含みます）をクラウドに保存し、ユーザーの他の端末に届けます。
   - **共有グループ**: グループは招待制です。グループに追加したもの（楽譜、共有に設定した書き込み、グループ名と画像）は、ユーザーの表示名・プロフィール写真とともにそのグループのメンバーに表示されます。非公開に設定した書き込みはグループ内に保存されますが、他のメンバーには表示されません。ただし、グループを削除する際にこれらも削除できるよう、グループの管理者は技術的にはこれにアクセスできる状態にあります（folino が管理者に表示することはありません）。
   - **同期・共有中の楽譜での状態**: 同期または共有されている楽譜を開いている間、ユーザーの他の端末とそのグループのメンバーには、ユーザーがその楽譜を閲覧中か編集中か、およびカーソルの位置が表示されます。この情報は楽譜を閉じるかオフラインになると削除されます。また、同期されている楽譜を編集している間は、二人が同時に編集しないよう、表示名を含む短時間の編集ロックを保持します。
   - **端末の識別子**: アプリのインストールごとに作成するランダムな識別子を、上記の状態・編集ロック・編集履歴とともに保存し、ユーザー自身の端末を区別するために使います。広告や追跡には使用しません。
   - **通報とフィードバック**: メンバーやグループを通報したり、フィードバックを送ったりする際は、ユーザーのメールアプリが当方宛てのメッセージを作成します。そこには対応に必要な識別子（グループ、メンバー、ユーザーのアカウントの識別子など）と、アプリのバージョン・OS のバージョン・端末モデルが含まれます。ユーザーがそのメールを送信しない限り、何も送られません。

   これらの情報は、サインイン、同期、グループでの共有、通報への対応といった機能の提供のためにのみ利用します。データは当方が利用するクラウド事業者に保存され、エンドツーエンドでは暗号化されていないため、サービスの運営者である当方はアクセスできる状態にあります。当方がアクセスするのは、サービスの運営、通報への対応、または法令の遵守に必要な場合に限ります。

folino は広告を表示しません。当方は個人情報を販売せず、他社のアプリやウェブサイトをまたいだ追跡にも利用しません。

## 委託先と個人情報の第三者提供

本ポリシーに記載した場合および法令に基づく場合を除き、個人情報を第三者に提供することはありません。次の事業者は、当方に代わってデータを処理する委託先（サービスプロバイダ）です。

- **Google（Firebase）**: サインイン（Firebase Authentication）、同期・共有データのクラウド保存（Cloud Firestore、Cloud Storage、Realtime Database）、サーバー処理、アプリの正当性の確認（Firebase App Check）、設定の配信、クラッシュレポート（Firebase Crashlytics）、利用状況の解析（Google Analytics for Firebase）
- **Resend**: サインイン用メールの配信
- **Apple および Google**: Apple でサインイン、Google でサインインを選んだ場合、各サービスがそれぞれのプライバシーポリシーに基づいてサインインを処理します。
- **GitHub**: folino は追加の楽器の音源を GitHub からダウンロードします。GitHub はネットワークアドレスなどの標準的な通信情報を受け取ります。

共有グループに追加したコンテンツは、その性質上、グループのメンバーと共有されます。

データは、日本、シンガポール、米国など、ユーザーの居住国以外の国で保存・処理される場合があります。

## データの保持と削除

- **クラッシュ・診断情報**は、クラッシュレポートサービスに一定期間保持された後に削除されます。Firebase Crashlytics は、クラッシュ情報を90日間保持した後、ライブおよびバックアップの各システムからの削除を開始します。
- **利用状況データ**は、解析サービスで当方が設定した保持期間（最長14か月）保持されます。
- **アカウントと同期データ**は、アカウントを削除するまで保持します。音符の編集履歴は、各編集からおよそ12か月後に自動で削除されます。「最近削除した楽譜」に移した楽譜は他の端末から取り除かれますが、サーバー上の写しはアカウントを削除するまで保持されます。
- **アカウントの削除**: 設定 → アカウント → 「アカウントを削除…」から、アカウントと、それに紐付けて保存されている楽譜・書き込み・編集履歴・プロフィール・写真を削除でき、参加しているグループからも退出します（最後のメンバーだったグループは削除されます）。存続するグループに追加した楽譜は他のメンバーが引き続き利用でき、すでに他のメンバーの端末にダウンロードされた写しを取り戻すことはできません。アカウントを削除しても、ユーザー自身の端末上のデータは削除されません。
- folino の利用に関するデータの開示・訂正・削除をご希望の場合は、下記のメールアドレスまでご連絡ください。
